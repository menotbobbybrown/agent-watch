USE CASES

What people actually use it for.

▶

Analyze competitor content

/watch https://youtu.be/... what hook did they open with?

The agent watches the first frames, reads the opening transcript, breaks down the structure. Ad creative, competitor launches, podcast intros — any video where how matters as much as what.

◉

Diagnose a bug from a recording

/watch bug-repro.mov what's going wrong?

Someone sends a screen recording. The agent finds the frame where the issue appears, describes what's on screen, often catches the cause without you ever opening the file.

⊘

Cut the hype out of a launch video

/watch https://youtu.be/... what's actually new — skip the hype

Strip a "game-changer" feature drop down to the few things that matter. Get the substance without ten minutes of intro and overselling.

≡

Turn a playlist into notes

/watch https://youtu.be/... summarize this to a note

Run it across a course or series. A channel becomes a searchable set of timestamped notes instead of hours you have to sit through.

HOW IT WORKS

Seven steps. The agent does all of them.

01

You paste a video and a question.

URL (anything yt-dlp supports — YouTube, Loom, TikTok, X, Instagram, 400+ more) or a local path (.mp4, .mov, .mkv, .webm).

02

yt-dlp checks captions first.

At transcript detail, captioned URLs return without downloading video at all. Otherwise downloads only what the run needs.

03

ffmpeg extracts frames at the chosen detail.

efficient decodes keyframes only (~0.5s). balanced prefers scene-change frames. JPEGs are 512px wide, clamped to 1998px tall.

04

Deduplication drops near-identical frames.

A 16×16 pixel brightness delta pass drops frames visually identical to the last kept one. A slide held for 90 seconds collapses to one frame. Budget is spent on distinct content.

05

Transcript from captions or Whisper.

First try: native captions — free, instant. Fallback: extract mono 16kHz audio (~480kB/min) and send to Whisper via Groq (whisper-large-v3, preferred) or OpenAI.

06

Frames + transcript handed to the agent.

Frame paths with t=MM:SS markers and timestamped transcript. The agent reads each frame in parallel as images in its context.

07

The agent answers — grounded in what's on screen.

Not "based on the description." It saw the frames. It heard the transcript. Cleanup removes the working directory when you're done.

WHAT YOU NEED

Captions are free. Whisper is cheap.

Captions cover the majority of public videos. Whisper only kicks in when there are genuinely no captions — local files, TikToks, some Vimeos.

Capability What you need Cost
Download + native captions yt-dlp + ffmpeg Free
Whisper fallback (preferred) Groq API key — whisper-large-v3 Cheap, fast
Whisper fallback (alt) OpenAI API key — whisper-1 Standard pricing
Disable Whisper entirely --no-whisper Free — frames only
◎
First run setup is automatic. On the first /watch call, the skill checks for ffmpeg / yt-dlp. If missing: macOS auto-runs brew install ffmpeg yt-dlp. Linux/Windows print exact commands. After that, preflight is silent — sub-100ms on every run.

Power flags
--detail transcript|efficient|balanced|token-burner Fidelity/speed dial
--timestamps T1,T2,… Grab a frame at exact timestamps
--max-frames N Lower frame cap for tighter token budget
--resolution 1024 Bump frame width for reading code/slides
--no-whisper Disable transcription — frames only
--no-dedup Keep near-duplicate frames
--whisper groq|openai Force specific Whisper backend
--out-dir DIR Keep working files at a specific path
